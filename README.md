# 📊 Student Exam Score Predictor

A Machine Learning project to analyze student-related factors and predict their exam scores.

> 🚧 **Status: In Progress**

## 🎯 Objective

The goal of this project is to understand how factors such as study hours, attendance, motivation, stress level, and learning style affect student exam performance and to build a model that can predict exam scores.

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook
