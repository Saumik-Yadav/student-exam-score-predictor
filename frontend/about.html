BEHIND SCOREPREDICT

A closer look at
what powers the prediction.

ScorePredict is an end-to-end machine-learning project that estimates a student's exam score from academic and lifestyle-related inputs.

01 / THE IDEA

Project overview

The goal is to explore how factors such as study time, attendance, sleep, study method and learning environment relate to exam performance. A trained regression model uses the submitted details to produce an estimated score.

16,000dataset records

02 / INPUT FEATURES

What goes into a prediction?

The model receives nine features describing a student's profile and routine.

AgeCourseStudy hours Class attendanceSleep hoursSleep quality Study methodFacility ratingExam difficulty
03 / DATA PREPARATION

Preprocessing pipeline

The dataset was checked and prepared before training. The identifier column was removed because it is not a meaningful predictor. Numerical and categorical columns are processed differently using a scikit-learn ColumnTransformer.

Numerical features

Age, study hours, attendance and sleep hours are standardised using StandardScaler.

Categorical features

Ordinal categories are encoded in a defined order, while course and study method use one-hot encoding.

04 / MODEL SELECTION

Why Linear Regression?

Several regression approaches were explored. The Linear Regression pipeline performed best among the evaluated candidates on the held-out test data, so it was selected for the current version.

R² score0.7331
MAE7.862

These are the recorded evaluation results for the current model. MAE and RMSE are expressed in score points when the target is measured on a 0–100 scale.

07 / IMPORTANT NOTE

A prediction, not a promise.

The output is an estimate based on patterns learned from the dataset. It should not be treated as a guaranteed exam result or as a measure of a student's ability. Predictions can be affected by dataset quality, model limitations and factors not represented in the inputs.
